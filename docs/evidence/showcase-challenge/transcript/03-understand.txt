Steps (flows). Every step also takes:
    kind: string  Which step.
    name: string  camelCase; later steps refer to its output as $<name>.
    description?: string  What it is for.
    when?: expr  Runs only when true; otherwise skipped, and its output unknown.
    retry?: string  { maxAttempts, backoffMs }: only on retryable errors.
  read: A governed read as the run's initiator.
    read: string  A read: { kind: query | object | related | aggregate, … }.
    timeoutMs?: number  Fail (retryably) after this long.
    onError?: fail | continue  continue: a source failure leaves the output unknown and the run goes on.
  compute: A pure value of earlier steps; replayed and compared, so deterministic.
    value: expr  The value.
  check: Fails the run with `message` unless `assert` is true (an unknown value is not true).
    assert: expr  A boolean.
    message: string  Why the run fails.
  ai: Asks a configured model (ADR-0074). Its input is released for the model's audience (ADR-0067); its answer is checked against `output` and treated as a proposal: an Action with side effects that uses it needs an approval of it first.
    model: string  A role in `models`.
    prompt: string  The instruction.
    input: expr-map  What the model is given.
    output: schema  JSON Schema the answer must satisfy.
    release?: refuse | redact  Default refuse.
  approval: Waits for a person the policy admits; never the initiator unless allowSelfApproval.
    policy: string  A policy rule.
    present: strings  Earlier steps the approver is shown.
    allowSelfApproval?: boolean  Default false.
    deadlineMs?: number  Expires (and compensates) after this long.
  action: Invokes an Action as the initiator: policy, input schema, preconditions and audit apply.
    action: action  The Action.
    input: expr-map  Its input.
    compensate?: string  { action, input }: undoes it; $output is this Action's output.
  parallel: Reads that do not depend on one another, run at once; each is referred to by its own name.
    steps: string  Read steps.
  forEach: One read per element of a list ($item), at most `max`: a longer list fails the step rather than being cut short.
    over: expr  A list.
    max: number  Most elements.
    read: string  The read, over $item.
    concurrency?: number  Reads at once; default 4.
